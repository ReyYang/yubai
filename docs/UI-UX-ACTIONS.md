# 余白 Figma 逐动作索引

2026-10-02。与 [Figma 交付说明](UI-UX-FIGMA.md) 一起阅读。编号对应真实画板，点击可定位；箭头表示已配置的演示目标，不代表每条路径已完成点击验收。输入与金额为固定合成示例。

主页面共用五个导航项及导入/新增入口；表单共用关闭、保存和取消。X 页是跨页面复用的控件状态，选择后返回调用表单。Mac 主要布局在末尾；具体业务状态复用相应手机编号。
