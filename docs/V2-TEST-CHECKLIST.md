## 主要使用流程

- [ ] 导入：导入一份真实账单，看整理结果、≤5 个问题、回答、整批撤销后账本恢复。
- [ ] 消费观：冷启动聊几句并确认；手动加一条想克制的领域和软线。
- [ ] 现在：制造一次超线，看到卡片；「以后别提」后消失；依据能打开记录详情。
- [ ] 来信与提醒：打开每周提醒开关，系统请求通知权限。
- [ ] 问余白：问一个数字问题（与 现在 的数字一致）；「把上周的美团都改成餐饮」出现确认；「把那笔 42 改成 24」被拒绝；买前问一件东西，加入心愿单；语音输入一句；截图记一笔并确认金额。

## 记忆与智能设置（2026-10-20 用户确认稿，尚未运行）

- [ ] 问答记下／撤销：聊一个长期计划，再聊一件在乎的事；回答底部逐条显示“✓ 已记下：…”和“撤销”。同一回答记多条各一行。撤销新增会删除，更新已有记忆后撤销恢复原话；后来手动编辑过的记忆不会被旧回答撤销覆盖。提案、记忆及使用标记保存失败时，不展示半份成功结果。
- [ ] 余白记得的：我 → 消费观与心愿单之间的入口；核对总数与本周新增数（新增0时只显示总数），分组按计划／在乎的事／生活情况，空组隐藏；核对全部六种中文来源、回访选择与日期，更新显示本周或实际日期及原话。没有记忆时仅出现指定空状态文字。
- [ ] 增删改：从问答新增，点开修改并保存，重开应用后仍在；左滑删除与编辑页删除均生效。空白、多行、超过200字不能保存；编辑过程中同步到较新内容时应阻止覆盖。
- [ ] 导入自由补充：选择“都不是”，补充用途；用途与 importAnswer 记忆同时保存，依据关联到问题记录。选项回答不自动记忆；整批撤销同时移除这批记忆，其他记忆保留，重新导入可处理。
- [ ] 每周回看：本周尚未回看且云端可用时，前台刷新后台执行一次；没有新管家卡也会执行。应用结果并刷新现有来信，不新增第二封；重开不重复。断网／无密钥／取消／无效响应／保存失败时静默且保留未完成周次，下次可重试；切账本、锁屏、同步选择期间不写入旧结果。
- [ ] 来信 learned：非空时在依据下出现 brand-tint“这周我对你多了解了一点”；每句“不对”移除该句及关联记忆，其他句保留。多张来信引用同一记忆时一起清理；learned 空时整卡隐藏。
- [ ] 这条还算数吗：用确认超过90天的领域／原则生成来信；amber 卡展示原话、写下月份、未动时长及有依据的近况（原则不编造次数）。learned 与 review 同时存在时 learned 在前。
- [ ] 回顾三个按钮：分别用独立测试副本点“还算数”（确认时间刷新、问题隐藏）、“改一下”（进入我的消费观，保存后旧问题隐藏）、“不需要了”（先展示现有删除提案，取消保留，确认才删除；只关闭提案弹层后能回到来信）。
- [ ] 买前判断：带日期的原则及领域原话显示“你 X 月写过”；未知时间明确说明未记录，超过180天提示可能变化。检查本地判断卡和模型文字均不漏掉原则，不沿用旧快照。
- [ ] 智能与隐私：我入口已配好显示 brand-tint 标签；云端开关、服务 DeepSeek、实际模型、钥匙串密钥入口和隐私说明按稿显示；保留原设备／提醒设置。模型页改名保存、重开仍生效，实际发送 JSON 使用新名字；设置 DEEPSEEK_MODEL 后环境名仍优先。密钥仍只在本机钥匙串，账本／备份不保存模型或密钥。
