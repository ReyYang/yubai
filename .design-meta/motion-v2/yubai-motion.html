触感 —

余白的动效：像水一样，有分量，不喧哗

左边的样机都能点：切标签、记一笔、点“今天”进账目、点右上角问余白、在洞察里切支出和收入。右边每一条都能单独“看一遍”。慢放 ×4 用来看清曲线，“减少动态效果”看系统设置打开后的样子。

边界 · 有创意，但守这九条

  • 一次只有一个主角每次操作只让一样东西带性格地动，别的只淡入淡出或跟着让位。几件事要发生时排先后，不同时抢。
  • 三档时长封顶反馈 ≤ 160ms；过渡 ≤ 450ms；品牌时刻整段 ≤ 700ms。超过就删，不靠加速补救。
  • 随时能打断动画进行中手指照样能点、能滑；新的动作从当前位置接上，不等上一段播完，不用延迟锁住输入。
  • 三条弹簧，不再加大面（页面、sheet、卡片）用 settle 不回弹；小控件用 snappy 微回弹；lively 只给记一笔圆钮和“记下”成功。
  • 位移有限控件和内容位移 ≤ 24pt，缩放只在 0.92–1.04；页面和 sheet 除外。除了水波，什么都不旋转。
  • 只有一处循环助手思考时的水波。其余动效都有终点，到了就停。
  • 落定才给触感记下、删除、撤销、到达底线提醒各一次系统触感；切标签、滚动、输入数字不给。
  • 玻璃只在浮层标签栏、记一笔圆钮、顶栏圆钮、返回胶囊、提示条、输入条和 sheet 是玻璃；卡片、数字、图表和列表永远是不透明的暖纸底。玻璃上不叠玻璃。
  • 减少动态效果位移、缩放、弹簧全部换成 160ms 交叉淡入；水位和图表直接终点；按压和触感照旧。

不做

滚动计数（先显示中间值）、视差和陀螺仪、卡片逐张入场、骨架屏闪烁、彩带与庆祝动画、3D 翻转、整页模糊转场、颜色渐变过渡（除了新行的底色褪去）、自动播放的提示动画。

选型 · 每件事只用一样

动效只用 SwiftUI 自带的：withAnimation 与三条弹簧、matchedGeometryEffect、navigationTransition(.zoom)、contentTransition(.numericText)、PhaseAnimator / KeyframeAnimator、sensoryFeedback，全部收在一个 YubaiMotion 里。不引入 Lottie 或其他动画包。图标用 SF Symbols 加设计系统里的自有记号，图表只用 Swift Charts。视觉跟 iOS 26 的 Liquid Glass 走，玻璃用系统的 .glassEffect 和系统控件，不自己画。这页样机本身只用浏览器自带的 Web Animations 和模糊材质，弹簧曲线按 SwiftUI 的 duration / bounce 算出来，所以手感和真机一致。
