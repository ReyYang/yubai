首页的主角：还能花那一个数，下面一条构成条和一行图例，告诉你这个数从哪来。

**使用者提供**：还能花、现金、要付和日常（信用卡 + 接下来要付 + 在存钱 + 日常开销）三个金额；需要留意的条数（可为 0）。

- 标签 `hero-label`，旁边 `caption` 写到哪天（“到 11月15日发工资”），数字 `amount-hero`；整块可点，进入计算依据（`Waterfall`）。
- 构成条：高 12、全圆端，两段，段间 `space-2`。条下一行图例（`caption`，8×8 方块 + 名字 + 数值），左右两端对齐。图例不能省：没有图例的条看不出在说什么。
- 够花（还能花 > 0）：整条 = 现金。`brand` 段 = 还能花，`neutral-soft` 段 = 要付和日常。图例“还能花 4,746.60”“要付和日常 2,171.54”。
- 超支（还能花 ≤ 0）：整条 = 要付和日常。`neutral-soft` 段 = 现金够付的部分，`amber-dot`/`amber-mark` 135° 斜纹段 = 还差。图例“现金 1,318.14”“还差 2,571.86”，还差的数值用 `amber-ink`。现金本身 ≤ 0 时整条斜纹，图例只写“还差”。
- 隐藏金额时：条和图例都不显示，只留打码的数字。
- 有需要留意的事时，图例下放一个 amber 提醒胶囊（`Pill`），没有就不放。
- 不要：在这里放第三个数字；给数字加卡片底或渐变；用绿色以外的颜色表示还能花；超支时让条变空或变成一整根灰。

源码：`Sources/YubaiApp/DesignSystem.swift` 的 `HeroCard`。第三十八轮前代码只有两段、没有图例、超支时一整根灰。
