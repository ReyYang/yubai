构成条：把一个整体按比例切成几段，回答“这一共是多少，分别是什么”。

**使用者提供**：各段的名字和数值；要强调的那一段。

- 高 8–14，全圆端，段间 `space-2`；下面一行图例：8×8 方块 + 名字 + 数值（数值用 `num`、`label`）。
- 着色：要强调的一段 `brand`，其余中性（`neutral-strong`、`neutral-soft`、`border-dashed`）；同类的多段（三个账户）用 `brand` → `series-2` → `series-3`；需要你处理的那段 `amber-mark`。
- 前后对比用两根条：“现在”整根 `series-soft`，“买完”= `brand` + 虚线框表示被拿走的部分，右侧写数。
- 只有两段的进度（目标、房租凑齐）：高 10，已有 `brand-mark`，剩余 `raised`。
- 很小的段给最小宽度（4–10），让它看得见。
- 超出（花的比能用的多、超了额度）：整条按“实际”画，不按上限截断。能覆盖的部分照常着色，多出来的一段接在后面：还能花用 `amber-dot`/`amber-mark` 斜纹，想克制的额度用 `amber-strong`。到上限和超了必须看得出差别。
- 不要：超过四段；在段上写字；用不同色相区分段。
