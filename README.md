# 余白 2.0

把钱理清，把生活留给自己。iPhone 优先，Mac 也能用；本地账本，无需注册。

| 入口 | 内容 |
|---|---|
| 现在 | 每周来信、管家卡片、保守可动用及计算依据、接下来要付的钱、导入账单 |
| 我 | 我的消费观、心愿单、账户与余额核对、导入记录、智能与隐私、备份与同步、使用指南 |
| 问余白 | 底部常驻入口；查询数字与依据、购买商量、一句话或截图补记、确认修改提案 |

第一次打开，选择「开始我的账本」，添加账户并填写此刻真实余额。在「我的消费观」写下原则、想克制与愿意多花的领域、储蓄目标和底线。保守可动用固定看未来 90 天，生活预留按历史支出估算；未来收入不提前当现金。点金额查看扣除了什么。

导入支持 CSV、TSV、XLSX。给付款方式对应实际账户，保存后点「整理」启动云端整理，完成或停下后显示至多五个问题；离线先保存，云端可用时再点整理。历史导入不会重复增加当前余额。在「我 → 导入记录」可整批撤销。安排由整理或问余白提出，待付款行可结束安排，已到期付款仍保留。记录详情从依据进入；删除后通过撤销或恢复版本找回。

云端智能默认关闭，在「我 → 智能与隐私」配置 DeepSeek。发送提问、消费观和任务需要的脱敏记录摘要，包括日期与金额；原始图片、账单文件、交易单号和来源指纹不发送给 DeepSeek。商户与备注可能进入摘要，脱敏不能识别所有姓名。「发给云端的内容」可查看本次打开期间最近 50 次发送。密钥保存在本机 Keychain，不进入账本或备份。数字由本机工具提供，修改需要确认，AI 不改已有记录的金额。

在「我 → 备份与同步」用至少 8 位密码保存完整加密备份。恢复前验证并保留原账本，最近 20 份修改前的版本也可恢复。默认仅本机。启用 iCloud 的构建可在此选择 iCloud，让 iPhone 与 Mac 共享账本及原始附件；冲突保留各版本，由你选择，不自动合并。构建默认不带 iCloud 权限，免费 Personal Team 可照常签名；启用方法见开发说明。

开发需要 Xcode 26 / Apple SDK，Swift 5 语言模式，最低 iOS 26 / macOS 14。打开 `Yubai.xcodeproj`，scheme 选 `Yubai`。构建和离线测试见 [DEVELOPMENT.md](docs/DEVELOPMENT.md)，真机签名见 [安装说明](docs/INSTALL-iPhone.md)。`dist/` 和旧截图属于 1.0 历史产物，不包含当前改动。Linux Core 验证与本轮改动记录见下方；Apple SDK 编译和设备验收仍待完成。

## 2026-10-29 · 第二十五轮「整理完剩下的」

导入整理后的问题优先显示；多笔未说明来源的进账合成一行，点开逐张处理，问题已覆盖的记录不重复提醒。剩余记录可「按对方分」，按笔数排序、搜索对方，收支分别成组；选好性质和需要的分类后，一次记好一组，可撤销并保留版本。旧兜底问题自动识别，剩余数随整理减少，零笔隐藏。转给自己需要选择另一个可用账户，没有时隐藏该选项。

页面沿用现有设计组件和 token，设计原稿只读、未入库。新增9项Core与2项UI测试；指定Linux完整测试599项、595通过／4原有实网跳过／0失败，App／UI条件语法解析及离线脚本链通过。Apple SDK编译与UI实跑待Mac。未提交、未增加第三方依赖。

## 2026-11-02 · 导入整理后台继续与提问延后

点「整理」后，iOS 26 尝试以用户发起的持续后台任务继续现有逐段整理，系统显示「整理导入记录／已整理 N / N」，与卡片共用千分位进度。系统停止和卡片「停下」均保留已完成段，再整理只发剩余；无法提交时保持屏幕常亮并显示「整理时别离开余白」。两条路径结束时都恢复此前的自动锁屏设置。

本次运行各批次的问题继续逐段保存，整理中暂不在现在页显示；完成、停下或失败后一起显示。重启时若无整理运行，已保存问题照常出现。外观保持，只增加系统标题与进度状态，既有前台提醒改为仅回退时显示。

新增 4 项 Core／4 项 UI 测试源码；指定 Linux Core 全量 608 项、604 通过／4 原有实网跳过／0 失败，App 的 iOS／macOS 和 UI 条件语法解析通过。UI 脚本默认跳过真实 BG 提交，仍覆盖常亮回退。Apple SDK 编译、XCTest UI 实跑与真机后台／锁屏、系统停止及受限提交仍待 Mac 验证。未提交、未增加第三方依赖。

手动验证后台整理：仅 Debug 模拟器可用。Mac 上安装 Debug App、启动 iOS 26 模拟器后运行：

```sh
SIMCTL_CHILD_YUBAI_UI_ALLOW_BACKGROUND=1 \
SIMCTL_CHILD_YUBAI_UI_TEST_SCRIPT=salary \
SIMCTL_CHILD_YUBAI_UI_TEST_CONFIGURED_KEY=1 \
SIMCTL_CHILD_YUBAI_UI_ORGANIZATION_SCENARIO= \
SIMCTL_CHILD_DEEPSEEK_API_KEY= \
xcrun simctl launch --terminate-running-process booted app.yubai.personal \
  --test-ledger "$(uuidgen)" -AppleLanguages '(zh-Hans)' -AppleLocale zh_CN
```

`salary`＋开关、不指定额外场景时，复用原 70 笔生成器，仅本模式扩为 150 笔待整理记录：30 笔／段，共 5 段，每段假回复等待约 8 秒，合计约 40 秒，全程不联网。点「整理」后立即回桌面，观察系统「整理导入记录」的进度；再运行一次命令可用新账本验证系统「停止」，回到 App 查看已完成段，再整理只处理剩余。若仍显示「整理时别离开余白」，表示系统未接受 BG 提交。未开启开关时，现有夹具、回复时序和 UI 测试的常亮回退保持；Release／真机不包含此开关。
