# 余白

把钱理清，把生活留给自己。余白是 iPhone 优先、兼顾 Mac 的个人资金管理软件，使用同一套账本和备份格式，无需注册。

## 安装

- **Mac**：打开 [Yubai-1.0.0-macOS-arm64.dmg](dist/Yubai-1.0.0-macOS-arm64.dmg)，把「余白」拖到 Applications，再从应用程序打开。适用于 Apple Silicon、macOS 14 或更新版本。
- **iPhone**：2026-10-08 已签名安装余白 1.0.0 到本人 iPhone；本人完成开发者信任后，蜂窝网络下验证无结果，切换 Wi-Fi 后验证完成并已打开余白。签名有效至 2026-10-15 17:32（Asia/Shanghai），当前状态和续签步骤见 [iPhone 安装说明](docs/INSTALL-iPhone.md)。历史未签名归档不能直接装进手机。
- [验证记录与当前限制](docs/VALIDATION.md) · [产品和技术调研](.scratch/yubai-product/research/2026-10-01-product-and-ui.md) · [开发构建](docs/DEVELOPMENT.md)

Mac 包使用本机临时签名，没有提交 Apple 公证。若 macOS 提示无法验证开发者，先确认它就是本项目生成的应用，再使用 Finder 的「打开」或系统设置的对应批准入口；无需关闭 Gatekeeper 或修改系统安全设置。版本号相同不代表替换包已获签名验证，可与 [SHA256SUMS.txt](dist/SHA256SUMS.txt) 核对。

## 第一次使用

1. 可以先进入独立示例账本；它不会写入你的真实账本。
2. 「开始我的账本」后添加实际持有资金的账户，填写此刻真实余额。微信里的银行卡支付属于银行卡，不能同时算成微信零钱；信用账户填写实际欠款，额度不算资产。
3. 在「我的」设置应急底线、每日生活预留和从今天往后看的天数。
4. 在「安排」填写房租、还款和已知收付款，按实际日期追踪。
5. 导入历史账单，给付款方式对应一次实际账户，处理少量异常后即可保存。开启云端智能后自动整理，不确定的地方最多问五个问题；离线也可先保存。
6. 在「我的 → 备份、恢复与导出」保存一份加密完整备份。

## 每天和每周怎么用

| 入口 | 能做什么 |
|---|---|
| 现在 | 查看保守可动用金额、逐项计算依据、未来资金曲线、近期安排和账户余额；可隐藏金额 |
| 账本 | 手动记账、搜索用途和单号、按时间/账户/分类/性质筛选、批量纠正、关联两侧转账、退款和计划、删除及恢复 |
| 安排 | 一次或周期收付款、目标预留、信用还款、房租月收季付和部分收付；已有付款可关联，避免重复记账 |
| 洞察 | 收支与分类、对比上一时段、零碎开销观察；购买前输入金额与用途，看对已有安排的影响 |
| 我的 | 账户核对、分类、偏好、账本锁、外观、完整备份/恢复、CSV 导出、原账单和恢复历史 |

文件支持 CSV、TSV 和 XLSX；中文编码支持 UTF-8、GB18030、UTF-16。微信/支付宝常见表头和带独立借/贷金额列的银行表格有自动识别；其他表头可由云端智能识别列，再由本机读取日期和金额；未开启智能时使用应用里的导入模板。多个文件按顺序整理。单文件最多 50 MB，最多 256 列、10 万行、100 万个单元格；金额不明确、币种不是人民币等异常不会自动入账。

截图可从相册或文件选择，也可将系统支持「用余白打开」的图像/账单送入应用。OCR 在设备上运行，金额需确认。当前没有单独的照片分享扩展；从照片分享菜单找不到余白时，直接在余白的「导入」中选择截图。

导入保留原文件和来源行。交易单号优先去重；没有单号时保留同一文件内合法的同额多笔。跨来源同时间同金额只提示疑似重复。已改记录不会被重导覆盖，已删记录不会因重导复活。新批次可在导入结果或「我的 → 导入批次与本地恢复」整批撤销，同时还原本次整理产生的关联和安排。

## 金额怎样算

账户余额以最近核对时刻为起点，加上之后实际发生的进出。历史导入用于补齐记录，不把旧收入再次加到今天的余额。重新核对会展示差额；只改账户名称不会偷偷改变余额起点。

**保守可动用 = 现金 − 信用待还 − 已知付款 − 目标预留 − 应急底线 − 日常生活预留 − 核对后新增的待明确流入。** 未来收入、基金市值、借出待收不提前当作现金。信用本金已经预留一次，还款计划不再次扣除本金。判断页会列出未核对、逾期和未知性质等依据缺口。

房租按给房东的整笔金额预留，朋友未到账的分摊不提前算现金；消费统计按本人承担比例计算。退款冲减消费，内部转账、借还本金和投资申赎不算普通收支。已有真实付款的约定保留原历史；金额或周期变化时，结束旧约定再建立接续约定。

每日生活预留为 0 时，按近 90 天小额日常支出的稳健中位数自动估算；填写的每日金额优先。

所有金额统一为人民币，内部使用整数分。软件不连接银行、不付款、不授信、不执行投资交易。

## 隐私、云端智能和跨设备

账本、原文件、OCR、文件数值解析、去重和资金计算都在本机。没有账户体系、遥测或自动网络同步。账本锁使用系统 Face ID、Touch ID 或设备密码；它不等同于账本文件单独密码加密。请使用设备的系统加密保护本机数据。

智能辅助仅使用 DeepSeek 云端模型。「我的 → 使用云端智能（DeepSeek）」默认关闭；开启后会把记录用途等任务摘要发送到 DeepSeek，用于整理分类、性质、用途、转账关联与周期安排，或补充购买思考、洞察文字和搜索词。金额、主账户和原始日期不由模型修改；确定的整理作为一次可撤销修改写入，不确定的地方留作问题。未配置密钥、离线或请求失败时先保存解析结果，智能可用后补整理。在「我的 → 智能辅助」保存或删除钥匙串密钥、测试连接、查看本次启动内的发送记录，或用临时「试问一句」查询只读账本工具。配置优先使用钥匙串，开发环境可回退到 `DEEPSEEK_API_KEY`；详见 [开发构建](docs/DEVELOPMENT.md) 和 [助手接口](docs/ASSISTANT.md)。本次助手骨架仅做静态复核，尚未构建、运行测试或完成设备验证。

完整备份包含原账单附件、账户、记录、整理问题、安排和目标；填写至少 8 位密码后使用 AES-GCM 加密，忘记密码无法恢复。空密码会导出未加密备份。CSV 仅用于查阅，不能代替完整备份。

在另一台设备恢复完整备份即可接续使用；恢复先校验、再预览、最后由你确认，当前账本会先保留。**一次只在一台设备编辑，再交接备份。** 恢复是切换到一份完整账本，不会双向合并。每次修改前自动保留最近 20 个完整版本；重要节点仍应另存备份。
