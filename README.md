# 余白 2.0

把钱理清，把生活留给自己。iPhone 优先，Mac 也能用；本地账本，无需注册。

| 入口 | 内容 |
|---|---|
| 现在 | 每周来信、管家卡片、保守可动用及计算依据、接下来要付的钱、导入账单 |
| 我 | 我的消费观、心愿单、账户与余额核对、导入记录、智能与隐私、备份与同步、使用指南 |
| 问余白 | 底部常驻入口；查询数字与依据、购买商量、一句话或截图补记、确认修改提案 |

第一次打开，选择「开始我的账本」，添加账户并填写此刻真实余额。在「我的消费观」写下原则、想克制与愿意多花的领域、储蓄目标和底线。保守可动用固定看未来 90 天，生活预留按历史支出估算；未来收入不提前当现金。点金额查看扣除了什么。

导入支持 CSV、TSV、XLSX。给付款方式对应实际账户，保存后自动整理，最多询问五个问题；离线先保存，云端可用时继续。历史导入不会重复增加当前余额。在「我 → 导入记录」可整批撤销。安排由整理或问余白提出，待付款行可结束安排，已到期付款仍保留。记录详情从依据进入；删除后通过撤销或恢复版本找回。

云端智能默认关闭，在「我 → 智能与隐私」配置 DeepSeek。发送提问、消费观和任务需要的脱敏记录摘要，包括日期与金额；原始图片、账单文件、交易单号和来源指纹不发送给 DeepSeek。商户与备注可能进入摘要，脱敏不能识别所有姓名。「发给云端的内容」可查看本次打开期间最近 50 次发送。密钥保存在本机 Keychain，不进入账本或备份。数字由本机工具提供，修改需要确认，AI 不改已有记录的金额。

在「我 → 备份与同步」用至少 8 位密码保存完整加密备份。恢复前验证并保留原账本，最近 20 份修改前的版本也可恢复。默认仅本机。启用 iCloud 的构建可在此选择 iCloud，让 iPhone 与 Mac 共享账本及原始附件；冲突保留各版本，由你选择，不自动合并。构建默认不带 iCloud 权限，免费 Personal Team 可照常签名；启用方法见开发说明。

开发需要 Xcode 26 / Apple SDK，Swift 5 语言模式，最低 iOS 18 / macOS 14。打开 `Yubai.xcodeproj`，scheme 选 `Yubai`。构建和离线测试见 [DEVELOPMENT.md](docs/DEVELOPMENT.md)，真机签名见 [安装说明](docs/INSTALL-iPhone.md)。`dist/` 和旧截图属于 1.0 历史产物，不包含当前改动。当前环境无 Swift 工具链，2.0 尚未完成编译或设备验收。
